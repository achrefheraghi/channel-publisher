# Channel Publisher

Channel Publisher is a private command-line tool. Its only user is its developer, Achref Heraghi, who uses it to publish videos to his own accounts on YouTube, Facebook, Instagram and TikTok: Lamplight Tales, Battles Redrawn, Day Zero Science, Day Without It and related channels.

It is not offered to the public, and no one else can sign up for it.

## What it does

With the channel owner's permission, it uses the YouTube Data API to:

- upload videos and set their title, description, tags, thumbnail and publishing time;
- update the channel's own description, keywords, banner and playlists;
- read basic statistics about the channel's own videos.

With the same owner's permission it also uses the Facebook and Instagram APIs (Meta) to publish videos and Reels to the developer's own Facebook Page and Instagram professional account, and the TikTok Content Posting API to send videos to the developer's own TikTok inbox as drafts, which he then reviews and publishes by hand in the TikTok app.
